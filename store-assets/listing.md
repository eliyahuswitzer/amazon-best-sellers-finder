=== START ===

Find the real Amazon best sellers — not the sponsored ads.

When you search on Amazon, the top results are often sponsored listings, not the products that are actually selling best. Amazon Best Sellers Finder adds a small floating button to any Amazon search or product page that takes you directly to the real Best Sellers list for whatever category you're browsing.

No more hunting through menus, no more guessing which sub-category a product belongs to, and no more wading through ads to find what's genuinely popular.


HOW IT WORKS

1. Search for anything on Amazon — for example, "toothbrush", "headphones", or "coffee maker".
2. A small orange "Best Sellers" button appears in the bottom-right corner of the page.
3. The extension reads the "Best Seller" badges Amazon itself shows on its results to identify which categories the top products actually belong to.
4. Click the button to jump straight to Amazon's Best Sellers page for that category.

If your search spans multiple Best Seller categories, you'll see up to 5 buttons stacked — one for each distinct category — so you can explore each top-100 list directly.


EXAMPLE

Search Amazon for "toothbrush" and the extension might show you buttons for:
• Manual Toothbrushes
• Electric Toothbrushes
• Kids' Toothbrushes

Each goes straight to Amazon's real, live Best Sellers page for that exact sub-category. No scrolling, no guessing.


FEATURES

• Floating "Best Sellers" button on Amazon search and product pages
• Automatic category detection using Amazon's own Best Seller badges — not guesswork
• Up to 5 category buttons when a search spans multiple Best Sellers categories
• Works on product pages too, using the product's Best Sellers Rank section
• Quick link from the toolbar popup for when the floating button is in your way
• Graceful fallback to Amazon's top-level Best Sellers if no specific category can be determined
• Zero configuration — install and it just works


PERMISSIONS

This extension only runs on amazon.com. It needs permission to read the current page (to detect which category you're browsing) and to fetch a small number of additional Amazon product pages in the background (to look up exact Best Sellers Rank data). That's it.

• No data is sent to any third-party server
• No analytics, no tracking
• No account required
• No changes to the pages you visit beyond adding the floating button


PRIVACY

This extension:
• Does NOT collect personal information
• Does NOT track your browsing history
• Does NOT send any data to a third-party server
• Runs entirely in your browser
• Only activates on amazon.com

Full privacy policy: https://eliyahuswitzer.github.io/amazon-best-sellers-finder
