How to export this as a 440×280 PNG

  1. Right-click anywhere on the orange/dark tile above and choose Inspect.
  2. In DevTools, make sure the selected element is <div class="tile">.
  3. Right-click that element in the Elements panel.
  4. Choose Capture node screenshot.
  5. A PNG will download at exactly 440 × 280 pixels, ready to upload to the Chrome Web Store.
Want to tweak the design? Edit the CSS in this file — colors, text, positioning are all in the .tile rules at the top. The title text lives in the <div class="title-block"> near the bottom of the file.
